## III. Background

Every computer is built from hardware components in four general categories: input devices, output devices, the processing/storage unit (CPU, RAM, drives), and ports/peripherals. Windows 11 provides built-in tools (Settings, System Information, Device Manager, Task Manager) to inspect these components without opening the case.

## IV. Procedure (Summary)

- **Part A – Physical Inspection:** list input devices, output devices, and ports.
- **Part B – System Identification (Settings):** Start → Settings → System → About.
- **Part C – Detailed Hardware Check:** System Information (msinfo32).
- **Part D – Device Manager Exploration:** expand at least six categories.
- **Part E – Performance and Storage Check:** Task Manager → Performance tab.
- **Part F – Software Snapshot (Optional / Bonus):** Settings → Apps → Installed apps.
